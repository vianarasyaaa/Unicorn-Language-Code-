# 📚 UNICORN Ω Libraries

**Status: belum ada library resmi.** Folder ini disiapkan untuk dokumentasi library setelah pencipta mengajarkan atau menyetujui nama dan API-nya.

Tidak ada API contoh di sini karena pencipta meminta agar sintaks, fungsi, dan perilaku tidak ditambahkan berdasarkan tebakan.

## Kapan sebuah library boleh ditambahkan?

Gunakan checklist berikut sebagai format kerja dokumentasi, bukan sintaks bahasa:

- [ ] Nama dan tujuan library disetujui pencipta.
- [ ] Nama operasi dan cara pemanggilan diberikan pencipta.
- [ ] Input dan output sudah dijelaskan.
- [ ] Perilaku gagal/error sudah dijelaskan atau ditandai belum diketahui.
- [ ] Status library (konsep, draf, prototipe, atau teruji) diberi label sesuai bukti.
- [ ] Contoh asli dan hasil pengujian disimpan.

Lihat [registry library](../docs/30-unicorn-omega/library-registry.md) dan [aturan kontribusi](../CONTRIBUTING.md).
