# ❔ Pertanyaan terbuka — keputusan milik pencipta

Halaman ini melacak hal-hal yang tidak boleh diputuskan oleh dokumentasi tanpa ajaran atau persetujuan pencipta.

| Topik | Yang sudah diketahui | Yang masih terbuka |
|---|---|---|
| `#sama#` tunggal | Contoh memakai `persamaan`, objek, dan `kenyataan::a:` | Definisi formal, konflik, dan aturan evaluasi |
| `#hampir#` tunggal | Contoh memakai `pencocokan`, objek, dan `kenyataan::a:` | Kriteria pencocokan dan nilai hasil |
| `#persis#` tunggal | Belum ada contoh mandiri yang disahkan di dokumentasi ini | Pola deklarasi dan hasilnya |
| Gabungan `#sama#` + `#persis#` | Contoh gabungan memakai `objek= "...*:a"` dan `kenyataan::a:` | Prioritas, penggabungan hasil, dan konflik |
| Alias `:a:` | Muncul dalam contoh objek/kenyataan | Lingkup, masa berlaku, aturan nama, alias ganda |
| Koma | Muncul di sejumlah contoh pencipta | Kapan wajib/opsional dan apakah konsisten per blok |
| `.unml` | Peran: struktur halaman | Grammar seluruh elemen dan nesting |
| `.uncs` | Peran: gaya/tampilan | Grammar deklarasi gaya |
| `.untext` | Peran: logika dan interaksi; ada contoh fungsi dan event | Grammar lengkap, signature, pemanggilan dan return |
| `.unt` | Peran: data website | Grammar tipe, objek data dan validasi |
| Library | Diminta untuk didokumentasikan | Nama, API, impor dan semantik belum diajarkan |
| Compiler/runtime | Belum tersedia di arsip | Implementasi, parser, eksekusi, diagnostics |

## Cara menutup sebuah pertanyaan

1. Tunggu contoh atau keputusan eksplisit dari pencipta.
2. Tambahkan teks aturan sedekat mungkin dengan penjelasan asli.
3. Tambahkan contoh persis yang diajarkan.
4. Perbarui README, registry, dan test dokumentasi jika relevan.
5. Jangan ubah status menjadi `TERUJI` sampai ada eksekusi nyata dan hasil yang tercatat.
