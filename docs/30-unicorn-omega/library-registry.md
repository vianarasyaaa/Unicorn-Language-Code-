**Status: registry resmi belum diisi.**

Pencipta meminta dokumentasi library, tetapi nama library, namespace, signature fungsi, dan cara impor/pemanggilan belum diajarkan. Untuk mencegah API palsu, halaman ini tidak menetapkan library atau pemanggilan fungsi sebagai resmi.

## Aturan memasukkan library

Sebuah library baru hanya boleh dimasukkan sebagai *creator-approved* setelah pencipta memberikan atau menyetujui:

1. Nama library dan tujuan.
2. Nama setiap fungsi/operasi persis seperti yang dipakai.
3. Bentuk deklarasi dan pemanggilan.
4. Bentuk input dan output.
5. Error atau hasil gagal yang mungkin muncul.
6. Apakah library bawaan, eksternal, opsional, atau platform-spesifik.
7. Contoh yang disetujui pencipta.
8. Cara menguji perilaku saat implementasi tersedia.

Daftar di atas adalah **formulir dokumentasi**, bukan sintaks atau fitur bahasa baru.
