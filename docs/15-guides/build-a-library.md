# Guide proposal: build a library

1. Define the canonical operations and public types.
2. Decide supported abstraction levels.
3. Write high-level wrappers over lower-level primitives.
4. Document errors, ownership, thread safety, and allocations.
5. Provide Indonesian and English aliases only where they improve usability.
6. Add tests for each alias to prove identical canonical behavior.
7. Add examples and benchmark only performance-critical paths.
8. Version the API and specify compatibility.
