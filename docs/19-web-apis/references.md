# Web API standards and references

External references may evolve; consult the canonical source when implementing a real provider or protocol.

- **HTTP Semantics (RFC 9110):** <https://www.rfc-editor.org/rfc/rfc9110.html>
- **MDN Fetch API:** <https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API>
- **MDN Using Fetch:** <https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch>
- **OpenAPI Specification:** <https://spec.openapis.org/oas/>
- **JSONPlaceholder mock REST API:** <https://jsonplaceholder.typicode.com/>
- **OWASP API Security Project:** <https://owasp.org/www-project-api-security/>
- **OWASP API Security Top 10, 2023:** <https://api-security.owasp.org/editions/2023/en/0x11-t10/>

This list is a starting point, not an endorsement of an external API for production use. Read provider-specific terms, security guidance, quotas, and data retention policies before integration.
