# Release Checklist

- [ ] Grammar dan semantik tidak berubah tanpa catatan.
- [ ] Semua contoh `.un` diberi status design-only atau telah diuji compiler versi tertentu.
- [ ] Conformance suite diuji pada target yang dinyatakan.
- [ ] API reference/generated docs diperbarui.
- [ ] Breaking changes dan migration notes ditulis.
- [ ] Security review dan dependency audit dilakukan.
- [ ] Sample tokens adalah placeholder palsu.
- [ ] Performance data punya metode, hardware, run count, dan commit.
- [ ] ZIP contents dan checksums diperbarui.
- [ ] Credit dan license status benar.
