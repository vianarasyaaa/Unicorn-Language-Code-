# Glossary UNICORN Ω

| Istilah | Arti |
|---|---|
| ABI | Application Binary Interface: kontrak binary/calling convention |
| AST | Abstract Syntax Tree hasil parsing |
| Backpressure | Mekanisme memperlambat/menolak producer saat consumer tertinggal |
| Backend | Komponen yang menghasilkan target machine/WASM/HDL |
| Borrowing | Mengakses resource milik pihak lain tanpa mengambil ownership |
| Deadline | Batas total waktu operasi |
| FFI | Foreign Function Interface |
| IR | Intermediate Representation antara source dan backend |
| Idempotency | Pengulangan operasi memiliki efek bisnis yang sama |
| Ownership | Aturan siapa yang bertanggung jawab mengelola resource |
| p95/p99 | Persentil latency untuk tail distribution |
| SSRF | Server-Side Request Forgery |
| WASI | Interface system untuk aplikasi WebAssembly |

Tambahkan istilah baru ketika API/semantik resmi ditetapkan.
