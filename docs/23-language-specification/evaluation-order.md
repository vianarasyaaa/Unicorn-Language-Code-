# Evaluation Order

Compiler harus menetapkan kapan argument dievaluasi, urutan efek samping, short-circuit operator, urutan pemanggilan, dan perlakuan overflow. Jangan membiarkan perilaku kritis bergantung pada optimisasi yang tidak terdokumentasi.

Sediakan contoh evaluasi dengan side effects dan conformance test. Jika urutan tidak dijamin, dokumentasikan dengan tegas.
