# Specification status labels

Use these labels consistently:

- **Idea:** concept only; syntax and semantics may change.
- **Draft:** described in documentation but not implemented.
- **Prototype:** partial implementation exists; no compatibility promise.
- **Implemented:** code exists and has tests for a named version/target.
- **Stable:** semantics, diagnostics, compatibility, and support policy are documented.
- **Deprecated:** still supported for a transition period but should not be used for new code.
- **Removed:** no longer accepted by the specified compiler version.

This archive is in the **Draft** stage unless a future implementation repository provides evidence otherwise.
