## Mengapa tidak ada puluhan operator tambahan?

Instruksi pencipta adalah agar dokumentasi tidak menambahkan aturan sebelum diajarkan. Variasi nilai dapat digunakan sebagai latihan pembahasan, tetapi tidak boleh diubah menjadi klaim grammar atau semantik baru tanpa persetujuan.
