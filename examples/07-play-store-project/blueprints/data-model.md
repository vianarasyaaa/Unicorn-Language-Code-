# Rencana data katalog aplikasi

> Model kebutuhan berbentuk tabel; bukan grammar `.unt`.

| Field rencana | Tujuan | Status |
|---|---|---|
| ID | Pembeda item di katalog | Usulan kebutuhan |
| Nama | Nama aplikasi | Usulan kebutuhan |
| Kategori | Pengelompokan | Usulan kebutuhan |
| Deskripsi | Ringkasan aplikasi | Usulan kebutuhan |
| Ikon | Lokasi aset visual | Usulan kebutuhan |
| Sumber resmi | Situs/halaman pengembang resmi | Usulan kebutuhan |
| Tautan instalasi | Tautan distribusi yang sah bila ada | Usulan kebutuhan; belum memiliki perilaku instalasi |

Belum ditetapkan apakah field wajib, tipe data, aturan keunikan, format penyimpanan, atau cara baca/tulis melalui UNICORN Ω. Tunggu ajaran pencipta sebelum mengubah tabel kebutuhan ini menjadi sintaks `.unt`.
